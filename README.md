# Java Data Structures

Implementation of fundamental data structures from scratch in Java while learning DSA.

## Data Structures Implemented

- Stack
- Linked List Stack
- Linear Queue
- Circular Queue
- Linked List Queue
- Singly Linked List
- Doubly Linked List
- Binary Search Tree

## Concepts Practised

- Generics
- Exception handling
- Encapsulation
- Pointer manipulation
- Iterative refactoring
- Git branching
